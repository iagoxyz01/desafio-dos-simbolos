# Desafio dos Símbolos

Jogo educativo de lógica matemática visual, feito com HTML, CSS e JavaScript puro. Não precisa de build, servidor local ou instalação de dependências para funcionar.

## Recursos

- Cadastro do nome da equipe.
- Cinco fases por partida, com símbolos e valores gerados aleatoriamente.
- Cronômetro global de 120 segundos.
- Resposta errada não trava o jogo: a equipe avança para a próxima fase.
- 100 pontos por resposta correta e bônus de velocidade de até 100 pontos.
- Ranking local automático usando `localStorage`.
- Integração opcional com Supabase para ranking compartilhado entre dispositivos.

## Rodar localmente

1. Baixe ou extraia os arquivos.
2. Abra `index.html` no navegador. Para desenvolvimento, também pode usar a extensão **Live Server** do VS Code.

## Publicar no GitHub Pages

1. Crie um repositório público no GitHub, por exemplo `desafio-dos-simbolos`.
2. Envie `index.html`, `style.css`, `script.js` e `README.md` para a raiz do repositório.
3. No repositório, acesse **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch `main` e a pasta `/ (root)`, depois clique em **Save**.
6. Aguarde o GitHub publicar. O endereço ficará parecido com `https://SEU-USUARIO.github.io/desafio-dos-simbolos/`.

O jogo funciona sem banco de dados, mas o ranking será salvo apenas no navegador em que cada equipe jogar.

## Configurar ranking compartilhado com Supabase

### 1. Criar projeto e tabela

1. Crie um projeto em [Supabase](https://supabase.com/).
2. Abra **SQL Editor** e execute:

```sql
create table public.scores (
  id bigint generated by default as identity primary key,
  team_name text not null,
  score integer not null,
  time_seconds integer not null,
  correct_answers integer not null default 0,
  created_at timestamptz not null default now()
);

alter table public.scores enable row level security;

create policy "Public can read scores"
on public.scores for select
to anon
using (true);

create policy "Public can submit scores"
on public.scores for insert
to anon
with check (
  char_length(team_name) between 1 and 35
  and score between 0 and 600
  and time_seconds between 0 and 120
  and correct_answers between 0 and 5
);
```

### 2. Configurar as credenciais públicas

1. No painel do Supabase, abra **Project Settings → API** (ou **Connect**, dependendo da interface).
2. Copie a **Project URL** e a chave pública **publishable/anon** do projeto.
3. No começo de `script.js`, preencha:

```js
const SUPABASE_URL = "https://SEU-PROJETO.supabase.co";
const SUPABASE_ANON_KEY = "SUA_CHAVE_PUBLICA";
```

A chave pública pode ficar no front-end se as políticas RLS estiverem configuradas corretamente. **Nunca** coloque uma chave `service_role` ou segredo privado no JavaScript público.

### 3. Testar

Publique novamente o `script.js` no GitHub. Ao terminar uma partida, os resultados serão enviados à tabela `scores`; o ranking consultará os resultados compartilhados. Se o banco ficar indisponível, o jogo continua e mantém uma cópia local.

## Regras de pontuação

- Resposta correta: 100 pontos.
- Resposta errada: 0 pontos naquela fase e avanço automático.
- Bônus de velocidade: até 100 pontos, calculado pelo tempo restante.
- Pontuação máxima: 600 pontos.

## Observação

O jogo é um front-end estático. A integração direta com Supabase é conveniente para um projeto educativo, mas qualquer ranking público pode receber envios automatizados. Para uma competição oficial, valide as pontuações no servidor e adicione proteção contra abuso.
